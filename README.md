# CheapBazzar

> A multi-vendor, multi-category e-commerce marketplace project.

## Project Status

**Planning phase** — requirements and architecture are being defined. Implementation has not started yet.

## Working Principles

- Build an original CheapBazzar experience inspired by familiar e-commerce usability patterns.
- Prioritize responsive UI, security, reliability, and performance.
- Finalize requirements and architecture before implementation.
